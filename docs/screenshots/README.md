# 演示素材目录

将截图放入本目录，供根目录 `README.md` 引用。

## 建议文件（纳入 Git）

| 文件 | 内容 |
|------|------|
| `demo-overview.png` | 整体界面：侧栏 + 欢迎页或对话区（关键运行截图） |
| `case-01-rag.png` | 测试样例 1：制度类问题 + 引用展开 |
| `case-02-multiturn.png` | 测试样例 2：多轮承接（如先问年假再问「需要」） |
| `case-03-fallback.png` | 测试样例 3：无关问题 / 未命中兜底 |
| `demo-streaming.gif` | （可选）流式输出短 GIF，建议 ≤ 15MB |

## 录屏（不纳入 Git）

| 文件 | 说明 |
|------|------|
| `demo-streaming.mp4` | 本地录屏即可，已加入 `.gitignore`；作业提交请用 **外链** 或 GIF / 截图代替 |

录屏建议 3～5 分钟，覆盖：启动 → 提问 → 流式回答 → 查看引用 → 新建对话。

在根目录 `README.md` 的「演示视频（外链）」处填写 B 站、飞书等链接。
